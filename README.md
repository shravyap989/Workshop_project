# Canteen Ordering System

A simple web-based canteen ordering system for a college or office canteen.

## Features

- Display food menu
- Add items to cart
- Place orders
- View order status
- Update order status
- View order history

## Technologies Used

- HTML
- CSS
- JavaScript
- Python Flask
- MySQL
